Tasting Workbench

와인 페어링 랩

요리 설명과 선택 사진으로 풍미를 분석하고 리뷰를 찾아 후보를 비교한 뒤 한 병을 골라 드립니다. 예제 데이터로 먼저 흐름을 확인해 보세요.

  1. 풍미 분석 재료와 조리법에서 단맛·산미·지방·향을 읽습니다
  2. 리뷰 검색 실제 연동 시 리뷰 인덱스에서 근거를 찾습니다
  3. 후보 비교 산도·바디·타닌·향을 기준으로 비교합니다
  4. 최종 추천 한 병과 짧은 이유를 정리합니다

테스트 설정

테스트 모드와 유형을 선택하고 요리 설명을 입력하세요.

테스트 모드

예제 모드는 준비된 고정 데이터를 쓰므로 네트워크 요청과 API 사용료가 없습니다.

리뷰 검색에서는 와인 스타일과 요청 건수를 지정할 수 있습니다.

빠른 예제

재료와 조리 방식, 느껴지는 풍미를 적어 주세요. 최대 2,000자.

JPG 파일, 최대 5MB. 실제 연동 시 사진을 풍미 분석에 사용합니다.

요리 설명이 비어 있습니다. 무엇을 먹는지 한두 문장 적은 뒤 다시 실행해 주세요.

결과

추천 보고서 또는 리뷰와 유사도 점수가 표시됩니다.

아직 실행되지 않았습니다. 조건을 정하고 ‘테스트 실행’을 눌러 주세요.

아직 결과가 없습니다

요리 설명을 입력하거나 예제를 선택한 뒤 테스트를 실행해 보세요.

  • 풍미 분석
  • 리뷰 근거
  • 후보 비교
  • 최종 추천
가이드 — 예제 모드, 실제 연동, 사진 제한
  • 예제 모드는 미리 준비한 고정 데이터로 동작합니다. 네트워크 요청도 API 사용료도 없습니다.
  • 실제 연동은 OpenAI와 Pinecone을 사용하며, 호출량에 따라 API 사용료가 발생할 수 있습니다.
  • 사진은 JPG만 받고 5MB를 넘으면 업로드되지 않습니다. 설명만으로도 추천할 수 있습니다.
  • 리뷰 검색은 선택한 스타일의 결과가 2건 미만이면 전체 스타일에서 다시 검색합니다.
