# 와인 페어링 랩

## 바로 테스트

브라우저에서 `index.html`을 열고 **버터 새우**, **버섯 리조또**, **버거 사진** 중 하나를 선택한 뒤 **테스트 실행**을 누릅니다. 예제 모드는 서버, API 키, 인터넷 없이 동작합니다. 예제 결과는 화면과 입력 흐름을 확인하기 위한 고정 데이터입니다.

## 실제 연동

프로젝트 루트에서 PowerShell로 실행합니다.

```powershell
python -m pip install -r requirements.txt
python degin_261124/server.py
```

브라우저에서 [와인 페어링 랩](http://127.0.0.1:8612/)을 열고 **실제 연동**을 선택합니다. 포트가 사용 중이면 `python degin_261124/server.py --port 8613`으로 실행할 수 있습니다. 서버를 종료하려면 터미널에서 Ctrl+C를 누릅니다.

실제 연동에는 기존 `.env`의 OpenAI 및 Pinecone 설정과 와인 리뷰가 적재된 인덱스가 필요합니다. 사진과 요리 설명은 기존 에이전트가 사용하는 서비스에 전달될 수 있으며 API 사용료가 발생할 수 있습니다.

## 프로젝트 구성과 테스트 범위

| 기존 파일 | 역할 | 화면에서 확인하는 방법 |
| --- | --- | --- |
| `step1_wine_data.py` | 리뷰 다운로드, 임베딩, Pinecone 적재 | 화면은 기존 인덱스를 조회합니다. 데이터 적재는 별도 CLI 작업입니다. |
| `step2_wine_pairing_agent.py` | 풍미 분석, 리뷰 도구 호출, 후보 비교, 최종 추천 및 보고서 정리 | **전체 페어링 추천**에서 같은 파이프라인을 실행합니다. |
| `search_pinecone.py` | 고정 문장으로 Pinecone 유사도 검색 | **Pinecone 리뷰 검색만**에서 에이전트의 리뷰 검색 도구에 요리 설명, 스타일, 건수를 전달합니다. |
| `showdata.py` | 원본 리뷰 데이터 일부 확인 | 데이터셋 확인용 CLI입니다. |
| `dish.jpg` | 버거 예제 이미지 | **버거 사진**에서 첨부와 미리보기를 확인합니다. JPG 파일을 직접 첨부할 수도 있습니다. |

리뷰 검색에서 스타일을 지정하면 기존 코드의 전체 스타일 재검색 조건이 적용됩니다. 반환 건수는 요청 건수와 다를 수 있습니다. 실제 연동에서 표시하는 추천 내용은 기존 에이전트의 최종 응답입니다.
