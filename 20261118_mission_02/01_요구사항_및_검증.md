| 요청 유형 | 질문 예시 | 필요한 도구 | 결과 |
| --- | --- | --- | --- |
| 일정 추천 | 오늘 부산으로 1박 2일 여행 가요. 숙소와 날씨를 고려해 코스를 추천해 줘. | `search_stays`, `get_weather` | 날짜별 방문 순서, 추천 이유, 숙소 후보, 7일 예보 |

| 날씨 조회 | 이번 주 서울 기온과 미세먼지 알려줘. | `get_weather` | 오늘부터 7일간의 예보 표 |
| 두 정보 조회 | 부산 숙소와 날씨를 같이 보여줘. | `search_stays`, `get_weather` | 숙소 후보와 예보 표 |
| 조건 확인 | 오늘 여행 갈 코스를 추천해 줘. | 없음 | “어느 지역으로 가시나요?” |

## 기능 요구사항

| ID | 요구사항 | 완료 기준 |
| --- | --- | --- |
| F1 | 질문에서 조건 추출 | 요청 유형, 도시, 시작일, 일수, 1박 예산, 실내·야외 선호를 정리한다. 한국시간 기준으로 날짜와 일수의 기본값은 오늘과 1일이다. 지역이 모호하면 확인 질문을 한다. |
| F2 | 필요한 도구 실행 | 요청 유형에 해당하는 함수만 허용한다. 실제 조회값이나 오류 상태를 `ToolMessage`로 모델에 전달한다. |
| F3 | 숙소 조회 | SQLite에서 도시와 1박 예산으로 검색한다. 예산이 주어진 경우 가격이 확인된 숙소만 예산 충족 후보로 분류한다. |
| F4 | 7일 예보 표시 | 날짜별 날씨, 최저·최고 기온, 최대 강수확률, PM10·PM2.5를 한 표에 표시한다. 예보가 없는 칸은 `—`로 표시한다. |
| F5 | 여행 동선 추천 | 각 날짜의 예보에 맞는 장소를 고르고 숙소와 같은 권역을 우선한다. 화면에서 방문 순서와 추천 이유를 함께 확인할 수 있어야 한다. |
| F6 | 모델 선택과 수업 기록 | OpenAI·Gemini 중 선택한 모델에 요청한다. 키 없는 수업 데모도 제공하며, 조건과 `Action → Observation`을 화면에서 확인할 수 있게 한다. |

## 추천 기준과 품질 요구사항

- **날씨와 선호**. 여행일의 최대 강수확률이 60% 이상이면 실내 코스를 우선한다. 그 외에는 사용자 선호를 고려한다. 예보를 받지 못한 경우에는 예보 미확인 상태를 알리고 실내 대안을 함께 제시한다. 60%는 수업용 추천 규칙이다.
- **예산과 동선**. 예산에 맞는 숙소를 기준점으로 삼고, 하루에 같은 권역의 관광지 2~3곳을 우선 묶는다. 적합한 숙소가 없으면 관광지 권역 중심으로 코스를 제안한다. 이 실습의 ‘최적’은 이 기준에 따른 추천을 뜻한다.
- **데이터 신뢰성**. 가격·날씨·미세먼지는 조회값을 표시한다. 수업용 데이터는 화면에 표시하고, 가격과 예보가 비어 있으면 확인 불가로 표시한다. 관광지 목록은 이름·권역·실내외 유형을 제공한다.
- **오류 복구**. 외부 요청에 시간 제한을 두고 ReAct의 반복 횟수에 상한을 둔다. 일부 조회가 실패하면 확보한 결과를 보여준다. 선택한 모델 호출에 실패하면 공급자와 실패 유형을 알린다.
- **키와 범위**. API 키는 서버 환경변수 또는 `.env`에서 읽는다. 대화나 실행 기록에는 키를 저장하지 않는다. 일정은 오늘부터 7일 안에 들어오는 1~3일로 제한한다.

| T2 요청별 분기 | 동일 도시로 날씨, 숙소, 두 정보 요청을 각각 실행 | 각 요청에 지정된 함수만 호출되고 표나 목록이 표시된다. | F2, F4 |
| T3 입력 확인 | 도시 없음 또는 7일 범위 밖 일정 | 확인 질문이나 지원 범위 안내가 나오고 조회 도구 호출은 0회다. | F1, F2 |
| T4 일부 데이터 누락 | 날씨 API 성공 · 대기질 API 실패 | 7일 기온과 강수확률이 남고, PM 칸에는 `—`와 조회 상태가 표시된다. | F4 |
| T5 예산 충족 후보 없음 | 기준을 넘는 가격과 가격 미확인 숙소만 있음 | 예산 충족 후보가 0건이며, 일정은 관광지 권역 중심으로 나온다. | F3, F5 |
| T6 모델 전환 | OpenAI, Gemini, 수업 데모를 차례로 선택 | 선택한 공급자만 호출되고 데모에서는 LLM 외부 호출이 0회다. | F6 |
| T7 반복과 실패 | 미등록 도구 요청, 반복 상한 도달 또는 숙소 도구 장애 | 허용된 호출만 실행하며, 실패와 남은 조회 결과를 화면에서 확인한다. | F2, F5, F6 |
