하루와 토리의 주문 도구 가게

도구를 등록하고, 다른 가게에 주문을 물어보고, 동네 어린이집을 찾아봐요.

차시 목차

  1. 첫 도구 가게를 열어요
  2. 편지를 보내고 답장을 읽어요
  3. 가방을 찾고 환불 접수증을 받아요
  4. 로봇에게 주문 도구를 건네요
  5. 도구와 규칙책과 빈 양식을 놓아요
  6. 다른 방의 도구도 벨로 불러요
  7. 어린이집 지도에서 정보 카드를 찾아요

3차시

코드 속에서는

연습 주문 서버는 GET으로 주문 기록을 찾고 POST로 환불 접수 응답을 만듭니다. 없는 주문에는 404를 돌려줍니다. 접수 뒤에도 예제 주문표는 그대로이며 결제 취소 단계는 구현되어 있지 않습니다.

}

가방과 USB-C 제품의 번호, 이름, 가격을 적어 둔 표예요.

s3_fastapi_server.py · 24~34행

@app.post("/api/orders/refund")
def request_refund(req: RefundRequest):
    order = ORDERS.get(req.order_id.upper())
    if not order:
        raise HTTPException(status_code=404, detail="Order not found")
    return {
        "order_id": req.order_id.upper(),
        "refund_status": "ACCEPTED",
        "reason": req.reason,
        "refund_amount_krw": order["amount_krw"],
    }

신청 이유와 주문표의 가격을 담아 접수 응답을 만들어요.
